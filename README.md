# GDG Portal — Master PRD v3.0

منصة Google Developer Groups (GDG) الإلكترونية الشاملة لإدارة التراكات، السيزونات، الإيفنتات، الأعضاء، والشهادات.

## 🌐 رابط الموقع المنشور

- **Production:** https://gdgnctu.vercel.app

## 🔑 بيانات الدخول التجريبية

| الدور | البريد الإلكتروني | كلمة المرور |
|-------|-------------------|-------------|
| Super Admin | `admin@gdg.com` | `admin123` |
| أي دور آخر | أي بريد + أي كلمة مرور | مثال: `student@gdg.com` / `123456` |

> ملاحظة: من صفحة "إنشاء حساب جديد" يمكنك اختيار الدور (Student / TrackHead / HR / SuperAdmin) وتجربة الصلاحيات المختلفة.

## ✨ الميزات

- **لوحة التحكم (Dashboard):** النقاط، الإنذارات، التراك الحالي، السيزون النشط، ولوحة المتصدرين.
- **مسار الدروس (Tracks Hub):** استعراض التراكات والوحدات والدروس وتسليم التاسكات.
- **التقويم (Calendar):** الإيفنتات والورش القادمة والسابقة.
- **لوحة التحكم الإدارية (HR & Admin):** مراجعة التاسكات، قبول/رفض، صندوق الشكاوي السرية.
- **بوابة التقديم (Recruitment):** استمارة انضمام أعضاء جدد + الشكاوي المجهولة.
- **الشهادات:** توليد شهادات PDF للإنجاز.

## 🏗️ البنية التقنية

- **Frontend:** React.js + Vite + Tailwind CSS (دعم كامل للعربية RTL).
- **Backend (اختياري للتشغيل المحلي الكامل):** Node.js + Express + SQLite (Sequelize).
- **Deployment:** Vercel (نسخة الواجهة الأمامية المستقلة).

## 💻 التشغيل المحلي

```bash
# تثبيت الحزم
npm install
cd client && npm install && cd ..

# تشغيل السيرفر (Backend) على المنفذ 5000
node server/index.js

# تشغيل الواجهة (Frontend) على المنفذ 3000
cd client && npm run dev
```
